# Security

Report vulnerabilities through GitHub private vulnerability reporting for this repository. Do not include private desktop screenshots, credentials, or personal information in a public issue.

OverInk stores no drawing history, has no network client, and includes no analytics or cloud sync. Drawings exist only in memory and disappear when the app quits. The app does not request Screen Recording, Accessibility, or Input Monitoring permission.

Release downloads are provided through GitHub. Community builds are ad-hoc signed unless their release notes explicitly say they were Developer ID signed and notarized. Only the latest release receives security fixes.
