# Changelog

## 0.1.1

- Rename the app from GlassPen to OverInk, including its bundle, Swift module, artifacts, and repository.
- Add a conventional Makefile interface for development, testing, packaging, and cleanup.
- Update GitHub Actions to current Node 24-based releases using immutable commit SHAs.

## 0.1.0

- Draw over any macOS app with a pen, highlighter, line, arrow, rectangle, or oval.
- Switch tools and colors from a drawing-only Liquid Glass control strip.
- Preserve fast freehand curves by capturing uncoalesced pointer samples through mouse-up.
- Preserve annotations while clicks pass through after drawing stops.
- Handle multiple displays, full-screen Spaces, and macOS Screenshot selection.
- Add automated tests, CI, and versioned universal DMG releases.
